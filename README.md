# תיקיית הגשות שוטפת

מרכז המעקב הקבוע נמצא ב-`Application_Tracker.html`. הוא מאחד את כל סבבי החיפוש ומפריד בין משרות להגשה, משרות שהוגשו וממתינות לתגובה, תהליכי ריאיון, הפניות/ניסיונות חוזרים, דחיות מעסיק, פסילות של ניר ומשרות לא פעילות. שינויי סטטוס בדף נשמרים מקומית בדפדפן; לאחר סבב עדכונים יש להעתיק ממנו את הסיכום לשיחה כדי לעדכן גם את קובצי המעקב.

זו התיקייה הפעילה למסמכים המוכנים להגשה. נשמור כאן רק גרסאות עדכניות שאפשר לצרף למשרה.

כללי העבודה:

- שם קובץ: `Nir_Shvarchberg_CV_<Company>_<Role>.docx`
- קורות חיים באנגלית כברירת מחדל, אלא אם הוחלט אחרת למשרה מסוימת.
- אין להוסיף ניסיון, הישגים, כלים או מספרים שלא אומתו.
- מותר לשנות ניסוח, סדר ודגשים כדי להתאים למשרה על בסיס ניסיון אמיתי.
- יעד עימוד: עמוד אחד, גוף טקסט 10pt, בדיקה ב־Word וב־LibreOffice.
- כתובת הדוא״ל הקבועה: `nir1shv@gmail.com`.
- גרסאות ביניים, רינדורים ופלטי בדיקה מועברים ל־`archive` ואינם נשמרים כאן.

סבב שני (18 באוגוסט 2026): נוספו 13 גרסאות ייעודיות למשרות Nexite, Plus500, Zenity, Trigo, TailorMed, CYE, Unframe, Cognyte, Adaptive6, Driivz, Plarium, Komodor ו־Skai. כל הקבצים נבדקו כעמוד A4 יחיד עם גוף טקסט 10pt הן ב־LibreOffice והן ב־Microsoft Word.

לכל אחת מ־13 הגרסאות של הסבב השני נשמר גם PDF תואם לצד קובץ ה־DOCX. כל PDF נבדק כעמוד יחיד, עבר חילוץ טקסט ואימות כתובת המייל, ונבדק ויזואלית לאחר הרינדור.

סבב שלישי (19 באוגוסט 2026): נוספו 21 ערכות מוכנות להגשה למשרות הפעילות M5–M25. שבע גרסאות נכתבו בהתאמה ייעודית למשרה, וב־14 המשרות שלא הצריכו גרסה ייחודית נשמר עותק של גרסת הבסיס המתאימה ביותר בשם החברה והתפקיד. לכל משרה קיימים DOCX ו־PDF; כל הקבצים נבדקו כעמוד A4 יחיד, עם גוף טקסט 10pt, כתובת הדוא״ל הנכונה ובדיקה חזותית מלאה של ה־PDF הסופי.

הגדרות ההתאמה והלמידה נמצאות ב־`search_profile.md` וב־`job_feedback.md` שבשורש סביבת העבודה.
